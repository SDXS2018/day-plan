# plan · Windows 悬浮每日清单

C# WPF + 本地 JSON。无需账号、云端服务或管理员权限。

## 已安装版本

- 程序：`%LOCALAPPDATA%\Programs\DailyPlan\DailyPlan.exe`
- 桌面和开始菜单：`DailyPlan 每日计划`
- 数据：`%LOCALAPPDATA%\DailyPlan\tasks.json`
- 上次保存备份：`tasks.json.bak`
- 设置与悬浮位置：`settings.json`

安装版采用低内存目录发布，运行时自带。请保留程序目录里的 DLL、Assets 和其他运行文件，使用桌面快捷方式启动即可。

## 使用

| 操作 | 方法 |
|---|---|
| 展开 | 点击 `plan 0/5` 小胶囊，每次默认回到今天 |
| 移动 | 按住胶囊拖动，位置自动保存；目前限定在主屏工作区 |
| 收起 | 按 Esc，或点击其他应用后自动收起；设置菜单返回面板内保持展开 |
| 新增 | 点击底部小加号展开输入框，输入后按 Enter 或再点加号；添加成功后自动收起 |
| 完成 | 点任务左侧圆圈；已完成自动排在下方，取消完成后回到上方并保留原先后顺序 |
| 重点突出 | 鼠标悬停任务后，点击右侧工具条的星形按钮；静态淡彩底色、清晰同色色边与左侧细色条，再点取消，标记自动保存 |
| 编辑 / 删除 | 鼠标移上任务后显示按钮，或右键任务 |
| 不同日期 | 日期左右箭头；日期带年份和中文星期并居中。今天为彩色渐变，过去灰淡，未来浅蓝虚线 |
| 跨日延续 | 未完成事项自动出现在后续日期，保留最初日期和颜色，不复制任务；完成后从次日起不再延续 |
| 今天继续 | 在其他日期右键任务选择“今天继续”，回到今天处理；原有过去日期保留 |
| 工作回顾 | 设置中点击“工作回顾”，默认全屏月历；点日期查看当天任务，支持翻月、最近7天和最近30天 |
| 设置 | 面板右上角省略号、胶囊右键、系统托盘右键 |
| 开机启动 | 设置菜单里手动开关；默认不启用 |
| 完全退出 | 菜单选择“退出 plan” |

正常启动只显示悬浮胶囊和系统托盘，不占任务栏。Alt+F4 隐藏到托盘。

胶囊可见尺寸约 100 × 32 个逻辑像素，外围留透明阴影空间。使用真正加粗的圆润中文字体，任务文字各有鲜艳颜色；任务操作按悬停显示。顶部只保留居中日期、前后切换和设置按钮。输入框默认折叠，Esc 可收起输入框并保留草稿。

清单按最长任务的实际字体宽度自动加宽，让日常标题尽量一行展示；最小332、最大900逻辑像素，并限制在屏幕内。特别长的标题换行完整显示，删除或缩短后重新收窄。重点任务使用对应颜色的静态淡彩底色、清晰色边与左侧细色条；已完成或取消重点后去掉突出效果。重点背景没有动画或计时器。

强调、编辑、删除统一收进右侧彩色圆角工具条，默认整组隐藏；鼠标悬停该任务时淡入，移开后隐藏。工具条按任务行高度垂直居中；预留工具宽度，显示/隐藏时文字不跳动。

日期、加号、日历选中状态、设置菜单共用粉绿蓝紫的珍珠渐变。设置开关使用圆角滑块，悬停和按压颜色保持一致。日历每格显示“完成/总数”；窗口较小时隐藏任务预览，右侧仍可滚动查看完整内容。F11切换全屏，右上角×关闭回顾。历史按保存的任务和完成时间重建；删除的任务不会出现在回顾中，也不会统计虚构工时。

面板按清单内容调整高度，同一外壳连续展开和收起，中途可反向，文字不随外壳重排拉伸。没有持续播放的后台动画。默认软件绘制方案在本机的100次连续开合测试中，私有内存约40–46 MB；该数值不代表所有机器或长期使用上限，详见验收记录。

## 构建

双击 `Build-Windows.bat`，生成 `release-fluid` 文件夹。本工作区可使用 `../tools/dotnet` 的 .NET 10 SDK，否则需要自行安装 .NET 10 SDK。

源码修复了初次 Windows 编译时的 WPF/WinForms 类型冲突，以及只读进度属性的双向绑定错误。

## 验证

最新验证见 `../verification/2026-10-25-日历版验收.md`。43项功能检查覆盖完成后排序、取消完成恢复顺序、重点保存、颜色升级、跨日延续、历史完成状态、跨月/跨年/闰年日历等；另有21项界面组件检查。此前动效和内存对比见 `../verification/2026-10-25-丝滑版验收.md`，不代表全屏日历的内存占用。

辅助功能实机测试可带 `--ui-test` 参数，暂时显示任务栏按钮；正式快捷方式不使用该参数。实际开机自启动仍需下次登录观察，验收时没有替用户重启电脑。
