DailyPlan / plan · Windows 每日计划

使用方法
1. 完整解压 ZIP，保留 DailyPlan 文件夹内的所有文件。
2. 便携版双击 current 文件夹中的 DailyPlan.exe；安装版使用桌面快捷方式。
   程序默认在屏幕右上角显示 plan 小按钮。
3. 点击按钮展开今天清单，按住小按钮可拖动。
4. 点击 + 新增任务，点击圆圈完成；已完成任务自动排到下面。
5. 鼠标悬停任务后显示重点、编辑、删除工具。重点为静态淡彩底色。
6. 日期左右箭头切换日期；未完成事项自动延续，完成后不再延续。
7. 三个点设置中可打开日历式工作回顾、检查更新、设置开机启动、关闭程序。
8. 点击其他应用自动收起；也可以在设置中关闭此选项。

运行环境
Windows x64。已包含 .NET 运行时，不需要安装 .NET SDK。
推荐首次使用下载同一版本的 Setup.exe，安装后自动创建快捷方式。
便携版完整解压后也可使用。请不要只移动或发送 EXE。

自动更新
启动后和运行期间自动检查，每24小时至多一次；检查失败不影响清单。
有新版时，三个点旁有小圆点，设置菜单显示发现的新版本。
在“检查更新”中下载，完成后点击“重启并更新”。下载过程中可继续使用。
已下载但未立即更新的版本，会在下次启动时应用。
请先保存正在新增/编辑的内容再重启。更新保留原任务、设置和悬浮位置。
更新服务使用 GitHub Releases，需要能够连接 GitHub。
旧的v1.0.0没有更新器，需要手动安装一次v1.1.0或更新版。

数据与更新
个人任务、设置和位置保存在当前账户的 %LOCALAPPDATA%\DailyPlan。
其他人首次使用会得到自己的空清单，不会看到制作者的个人任务。
从旧便携版迁移时，先在托盘或设置中退出旧版，再安装新版；不需要删除任务数据。
快捷方式可以由用户手动创建，开机启动默认关闭。
